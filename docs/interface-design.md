# 界面设计与交互

日期：2026-10-21。此次调整覆盖八个页面，继续使用现有 React、API 与数据模型。

## 工作空间

保留“系统总览 / 模拟服务 / 采集网关”的导航结构。桌面端使用深色固定侧栏与浅色工作区，当前页面通过图标、背景和左侧标记定位。面包屑与时间位于固定顶栏。

手机和平板窄屏通过菜单按钮打开导航抽屉，支持 Escape、遮罩关闭、键盘焦点限制与关闭后焦点返回。选择页面后自动关闭抽屉。

## 页面层级

- 系统总览：服务指标、设备到 Kafka 的数据链路、采集机组概况、快捷入口和需要关注的运行状态。未获取或过期的数据有明确状态，不显示为链路正常。
- 模拟服务总览：服务信息与节点类型分布并列展示。
- 数据监控：统计信息压缩为紧凑摘要，表格使用固定表头、容器滚动、统一筛选与分页，节点管理操作保留文字标签。
- 模拟配置：基本设置、节点动态值和业务规则分区；节点参数表去除重复的可见标签，保留辅助技术可识别的字段名称。
- 网关运行总览：投递趋势增加图例和参考线，连接、采集就绪、协议探测与消息确认分别展示。
- 连接配置与网关设置：主要编辑表单排在前面，差异和历史版本按需展开；底部操作区区分校验、仅保存与保存并应用。

表单草稿仍在切换页面时保留。设备写入继续执行回读确认，未知结果保持为待确认，不自动重复写入。HTTP 管理无需令牌。

## 组件与可读性

统一颜色、字号、间距、圆角、边框、图标、状态标签及错误提示。装饰图标使用本地 SVG，不依赖远程图片或字体。状态同时提供文字和颜色，普通文本与主要控件保留对比度检查。

窄屏表单采用单列排列，数据表格在自身容器内滚动。模拟参数表隐藏标签定位于各自字段，防止绝对定位内容导致页面横向溢出。
